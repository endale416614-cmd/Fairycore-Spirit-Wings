# Fairycore - Spirit Wings

Fairycore - Spirit Wings adds Venenum and Pixie genes in its Wings category, along with twenty wing genes and four fairy races.

A RimWorld mod by Faeris, version 2.06. Workshop page: https://steamcommunity.com/sharedfiles/filedetails/?id=3812515333

## Install

Copy this folder into `RimWorld/Mods`, enable the mod and load it after Harmony.

Skill effects and sounds in this repository are made for this release, so they differ from the Workshop version.
